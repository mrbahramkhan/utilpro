STEP 1

Apply for Google AdSense

Before anything else, you need an approved AdSense account. Make sure your site is live and has content first.

✅ Requirements You Already Meet

  • Original content (20+ articles)
  • Privacy Policy page (/privacy.html)
  • Contact page (/contact.html)
  • Clean, no-popup design
  • Mobile responsive layout
  • About page (/about.html)

⚠️ Do Before Applying

  • Deploy site with a real domain (not localhost)
  • Have at least 20–30 organic visitors/day
  • Wait 2–3 weeks after publishing content
  • Make sure site is indexed in Google
  • Add Google Search Console
Apply at adsense.google.com →
STEP 2

Add Your Publisher ID to Every Page

After approval, Google gives you a Publisher ID (looks like ca-pub-1234567890123456). Add it in two places:

Option A — Automatic (via js/ads.js)

Open js/ads.js and update line 14:

// BEFORE (demo mode): publisherId: 'ca-pub-XXXXXXXXXXXXXXXX', demoMode: true, // AFTER (production): publisherId: 'ca-pub-1234567890123456', // ← your real ID demoMode: false, // ← disable demo

Option B — Manual (in each HTML <head>)

Add this script to every page's <head> tag:

<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX" crossorigin="anonymous"></script>

✅ Fastest method: Add the script to your shared header snippet only once. The ads.js file already handles this automatically when demoMode: false.

STEP 3

Create Ad Units in AdSense Dashboard

In AdSense, go to Ads → By ad unit → Create new ad unit. Create these 3 essential units:

📰 Unit 1: Leaderboard (728×90) Highest CTR
Settings: Display ads → Responsive → Horizontal
Used on: Top of every page below header
Copy the Slot ID → paste in ads.js → adUnits.leaderboard
⬛ Unit 2: Rectangle (300×250) Best for Sidebar
Settings: Display ads → Responsive → Square
Used on: Article sidebars, mid-content
Copy the Slot ID → paste in ads.js → adUnits.rectangle
📄 Unit 3: In-Article (Native) Recommended
Settings: In-article ads → Automatic styling
Used on: Inside article content, between sections
Copy the Slot ID → paste in ads.js → adUnits.inArticle
STEP 4

Replace Ad Placeholder Divs (Manual Method)

If you prefer manual control, replace each .ad-slot div with an actual AdSense unit:

<!-- REPLACE THIS placeholder: --> <div class="ad-slot ad-slot-horizontal"> <div>📢 Advertisement</div> </div> <!-- WITH THIS real AdSense unit: --> <div style="min-height:90px; text-align:center;"> <ins class="adsbygoogle" style="display:block" data-ad-client="ca-pub-XXXXXXXXXXXXXXXX" data-ad-slot="XXXXXXXXXX" data-ad-format="auto" data-full-width-responsive="true"></ins> <script> (adsbygoogle = window.adsbygoogle || []).push({}); </script> </div>

✅ Pro tip: Set demoMode: false in ads.js and it does this replacement automatically — no need to edit 40 HTML files manually!

STEP 5

Enable Auto Ads (Optional but Recommended)

Auto Ads lets Google place additional ads automatically where they'll perform best. Enable it in AdSense:

  1. Go to AdSense → Ads → Overview
  2. Click on your site name
  3. Toggle Auto ads ON
  4. Click Apply to site
  5. Auto ads will appear within 20–30 minutes

⚠️ Auto Ads can sometimes place too many ads. Monitor your ad density — Google recommends no more than 3 ads per screen height. Check in AdSense → Ads → Auto ads → Ad load settings.

💡 Revenue Optimization Tips

Use responsive ad units — they automatically resize for mobile and desktop, maximizing fill rate.
Place ads above the fold — the leaderboard below the header is the most valuable position.
In-article native ads blend with content and get 2–4x higher CTR than display ads.
A/B test ad positions — use AdSense's built-in experiments to test which placements earn more.
Avoid too many ads — Google penalizes sites with poor ad-to-content ratio. Max 3 ads per page is recommended.
Use anchor ads (mobile) — a sticky bottom banner on mobile converts well. Enable in Auto Ads settings.
Target high-CPC keywords — Finance (EMI, loans) and tech keywords get Rs.30–100+ per click in Pakistan.

SEO

Submit Sitemap to Google Search Console

Speed up indexing of all 40 pages by submitting your sitemap to Google.

  1. Go to search.google.com/search-console
  2. Add property → Enter your domain → Verify via DNS or HTML file
  3. Go to Sitemaps in the left menu
  4. Enter: https://yourdomain.com/sitemap.xml
  5. Click Submit — Google will start crawling within 24–48 hours

✅ UtilPro's sitemap.xml already includes all 40 pages with proper priority and changefreq values. Just update the domain name from utilpro.net to your actual domain.
